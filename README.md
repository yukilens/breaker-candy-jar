# ブレーカー・キャンディジャー

家電の消費電力をキャンディの粒で積み上げて、契約 30A（≒3,000W）の目安を超えそうかを確かめるスマホ向け Web アプリ。

- 公開ページ: https://yukilens.github.io/breaker-candy-jar/
- 1粒 = 1pt = 100W。ジャーの容量は 30 粒（3,000W）。使用中にすると粒が上から降ってきて溜まる。超えるとフタが外れて粒があふれる
- サーバー・ログイン・外部 API なし。ブラウザだけで動き、状態は `localStorage` に保存

> 3,000W は家全体の簡易目安で、安全を保証するものではありません。回路ごとの 20A 制限や電源投入時の電流などで、目安未満でもブレーカーが落ちることがあります。

## 使い方

- カードをタップ → 使用中／OFF
- モードボタン（PC 中／高、ストーブ 通常／点火時、レンジ／オーブン）→ 同じ機器の排他モード。使用中の機器はまず「変更後」をプレビュー
- 「もし動かしたら？」→ 追加前→追加後・増加分・超過見込みを表示（うすい粒＝追加分）。「使用中に追加」で確定
- 「W を編集」→ 実測値に書き換え（保存される）／「W を初期値に戻す」
- 「全部OFF」「おすすめ初期状態」（ストーブ通常＋冷蔵庫・照明など）

## ローカルで動かす

ビルド不要。`index.html` をブラウザで直接開けば動く。

```sh
# もしくは簡易サーバー
python -m http.server 8000   # → http://localhost:8000/
```

計算のテスト（受け入れ条件）:

```sh
node test_calc.js
```

## ファイル構成（編集箇所）

| ファイル | 中身 |
|---|---|
| `data.js` | 家電の初期データ（名前・アイコン・色・モードと W）、おすすめ初期状態 |
| `calc.js` | 計算（W 合計・プレビュー・pt 換算・しきい値）。表示から独立 |
| `app.js` | 画面描画（キャンディジャー SVG）と操作 |
| `style.css` | 見た目 |
| `test_calc.js` | 計算の確認スクリプト |

- 上限・注意しきい値は `calc.js` 冒頭の `LIMIT_W`（3000）と `WARN_W`（2700）
- 保存キーは `breaker-candy-jar:v1`
